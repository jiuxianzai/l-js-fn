l-js-fn v3.x 文档归档 ​

WARNING

本页面为 v3.x 历史版本文档归档，该版本已停止维护，仅作存档参考。建议升级到最新版本，如需了解 v4 的破坏性变更，请查看迁移指南。

版本概览 ​

v3.x 是引入分包模块化后的版本线，所有函数改为按需导入，全面支持 Tree-shaking，并新增了子模块入口（bom、ws、storage、polling、ipc、encode、file、event-bus、crypto、uniapp 等）。

安装 ​

bash
npm install l-js-fn@3

模块列表 ​

模块说明
is-kit类型判断（空值、数组、邮箱、身份证、手机号等）
array-kit数组操作（增删改查、分页、分组、随机抽样等）
string-kit字符串处理（脱敏、去除空格、UUID、序号生成等）
object-kit对象操作（合并、过滤、FormData 转换等）
common通用工具（防抖、节流、深拷贝、设备检测等）
date-kit日期处理（格式化、计算、相对时间等）
number-kit数字处理（格式化、百分比、随机数等）
url-kitURL 处理（参数解析、拼接、转换等）
color颜色处理（HEX/HSL 转换等）
Result结果类（v4 已移除）
encode编码解码（Base64、HTML 转义、URL 编码等）
crypto加密模块（MD5、AES、RSA、SM2、SM4 等）
uniapp小程序工具集

与 v4.x 的主要差异 ​

能力v3.xv4.x
命名规范混合命名（groupBy/pick/diffDays 等）统一前缀（arrayXxx/objXxx/dateXxx）
数组删除4 个 arrayDelXxx合并为 arrayRemove/arrayRemoveAt/arrayRemoveBy
对象合并objMerge（破坏性）+ deepMerge统一为 objMerge（非破坏性）
查询字符串querystringify/parseQueryString统一到 transUrlParams/getUrlParams
Result 类存在已移除

v3 → v4 的完整迁移对照表请查看迁移指南。
