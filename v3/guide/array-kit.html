array-kit — 数组操作 ​

数组操作工具集，提供增删改查、分页、分组、随机抽样等常用功能。

1. arrayDelEl 删除指定元素 ​

从数组中移除指定元素，返回新数组。

参数说明：

参数类型必填说明
arrT[]是原数组
targetT是要删除的目标元素
keykeyof T | null否对象数组的属性名（用于匹配对象）

返回值： T[] — 新数组

示例：

ts
import { arrayDelEl } from 'l-js-fn';

// 基本类型
arrayDelEl([1, 2, 3, 2], 2); // [1, 3]

// 对象数组（通过 key 匹配）
const users = [
  { id: 1, name: 'Alice' },
  { id: 2, name: 'Bob' }
];
arrayDelEl(users, { id: 2, name: 'Bob' }, 'id');
// [{ id: 1, name: 'Alice' }]

// 对象数组（JSON 序列化匹配）
arrayDelEl(users, { id: 1, name: 'Alice' });
// [{ id: 2, name: 'Bob' }]
js

// 对象数组（JSON 序列化匹配）

// [{ id: 2, name: 'Bob' }]

25. arrayToString 过滤空值后拼接字符串 ​

过滤掉数组中的空值（null、undefined、空字符串 ''）后，按顺序拼接为字符串。常用于签名串拼接、多字段值合并等场景。

参数说明：

参数类型必填说明
arrT[]是需要处理的数组
separatorstring否分隔符，默认为空字符串 ''，与 join 的语义一致

返回值： string — 拼接后的字符串；非数组或空数组返回 ''

说明： 仅过滤 null、undefined、'' 三种空值，保留 0、false 等值

示例：

ts
import { arrayToString } from 'l-js-fn';

arrayToString(['a', null, 'b', '', 'c']);            // 'abc'
arrayToString([1, 0, false, null, '', 2]);           // '10false2'
arrayToString(['a', 'b', 'c'], '&');                 // 'a&b&c'

// 典型场景：签名串拼接
const signStr = arrayToString([
  form.username,
  form.password,
  form.phone,
]);
js
import { arrayToString } from 'l-js-fn';

arrayToString(['a', null, 'b', '', 'c']);  // 'abc'
arrayToString(['a', 'b', 'c'], '&');       // 'a&b&c'
js
