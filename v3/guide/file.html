file — 文件处理 ​

文件处理工具集，提供文件大小格式化、类型判断、下载、读取等功能。

导入方式：

方法已全量平铺到主包 l-js-fn，可直接从主包导入（Tree-shaking 只打包用到的函数）；子路径 l-js-fn/file 仍保留，供 CJS 或需要精确加载的场景使用。

ts
import {
  formatFileSize, getExtension, getFileName,
  downloadFile, readAsText, readAsDataURL, readAsArrayBuffer,
  isImage, isVideo, isAudio, isPDF
} from 'l-js-fn';
js
import {
  formatFileSize, getExtension, getFileName,
  downloadFile, readAsText, readAsDataURL, readAsArrayBuffer,
  isImage, isVideo, isAudio, isPDF
} from 'l-js-fn';
js
const {
  formatFileSize, getExtension, getFileName,
  downloadFile, readAsText, readAsDataURL, readAsArrayBuffer,
  isImage, isVideo, isAudio, isPDF
} = require('l-js-fn/file');

1. FileSizeUnit ​

文件大小单位枚举：

ts
enum FileSizeUnit {
  Byte = 'B',
  KiloByte = 'KB',
  MegaByte = 'MB',
  GigaByte = 'GB',
  TeraByte = 'TB'
}

2. FileSizeInfo ​

文件大小信息接口：

ts
interface FileSizeInfo {
  formatted: string;  // 格式化后的字符串
  value: number;      // 数值
  unit: FileSizeUnit; // 单位
}

3. formatFileSize 格式化文件大小 ​

格式化文件大小。

参数说明：

参数类型必填说明
bytesnumber是文件大小（字节）
optionsobject否配置选项
options.precisionnumber否小数精度，默认 2
options.base1024 | 1000否进制基数，默认 1024

返回值： FileSizeInfo

异常： 参数非法时抛出 TypeError

示例：

ts
import { formatFileSize } from 'l-js-fn';

formatFileSize(1024);
// { formatted: '1 KB', value: 1, unit: 'KB' }

formatFileSize(1536000);
// { formatted: '1.46 MB', value: 1.46, unit: 'MB' }

formatFileSize(1024, { precision: 0 });
// { formatted: '1 KB', value: 1, unit: 'KB' }

formatFileSize(1000, { base: 1000 });
// { formatted: '1 KB', value: 1, unit: 'KB' }
js

4. getExtension 获取文件后缀 ​

获取文件扩展名（包含点号）。

参数说明：

参数类型必填说明
filenamestring是文件名或文件路径

返回值： string — 文件扩展名，无扩展名返回 ''

示例：

ts
import { getExtension } from 'l-js-fn';

getExtension('image.png');          // '.png'
getExtension('/path/to/file.txt');  // '.txt'
getExtension('filename');           // ''
getExtension('.gitignore');         // '.gitignore'
js
import { getExtension } from 'l-js-fn';

getExtension('image.png');          // '.png'
getExtension('/path/to/file.txt');  // '.txt'
getExtension('filename');           // ''
getExtension('.gitignore');         // '.gitignore'
js
const { getExtension } = require('l-js-fn/file');

getExtension('image.png');          // '.png'
getExtension('/path/to/file.txt');  // '.txt'
getExtension('filename');           // ''
getExtension('.gitignore');         // '.gitignore'

6. downloadFile 下载文件 ​

触发浏览器下载文件。

参数说明：

参数类型必填说明
blobBlob | File是Blob 或 File 对象
filenamestring是下载的文件名

返回值： void

示例：

ts
import { downloadFile } from 'l-js-fn';

// 下载文本文件
const blob = new Blob(['Hello World'], { type: 'text/plain' });
downloadFile(blob, 'hello.txt');

// 下载 JSON 数据
const data = { name: 'John', age: 20 };
const jsonBlob = new Blob([JSON.stringify(data, null, 2)], { type: 'application/json' });
downloadFile(jsonBlob, 'data.json');
js

7. readAsText 读取为文本 ​

读取文本文件内容。

参数说明：

参数类型必填说明
fileFile是File 对象
encodingstring否文本编码，默认 'utf-8'

返回值： Promise<string>

示例：

ts
import { readAsText } from 'l-js-fn';

const input = document.querySelector('input[type="file"]');
input.addEventListener('change', async (e) => {
  const file = e.target.files[0];
  const content = await readAsText(file);
  console.log(content);
});
js

10. 文件类型判断 ​

10.1 isImage 判断图片文件 ​

判断是否为图片文件。

参数说明：

参数类型必填说明
filenamestring是文件名或扩展名

返回值： boolean

支持的格式： jpg、jpeg、png、gif、bmp、webp、svg、ico、tiff、psd、raw、heic、heif

示例：

ts
import { isImage } from 'l-js-fn';

isImage('photo.jpg');    // true
isImage('image.png');    // true
isImage('document.pdf'); // false
js
import { isImage } from 'l-js-fn';

isImage('photo.jpg');    // true
isImage('image.png');    // true
isImage('document.pdf'); // false
js
const { isImage } = require('l-js-fn/file');

isImage('photo.jpg');    // true
isImage('image.png');    // true
isImage('document.pdf'); // false
