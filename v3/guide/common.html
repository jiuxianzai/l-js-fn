common — 通用工具 ​

通用工具函数集，提供防抖、节流、深拷贝、设备检测等常用功能。

1. sleep 睡眠延迟 ​

睡眠函数，延迟指定毫秒数。

参数说明：

参数类型必填说明
timenumber是睡眠时间（毫秒）

返回值： Promise<void>

示例：

ts
import { sleep } from 'l-js-fn';

async function demo() {
  console.log('开始');
  await sleep(1000); // 等待 1 秒
  console.log('1 秒后');
}
js
import { sleep } from 'l-js-fn';

  console.log('开始');
  await sleep(1000); // 等待 1 秒

}

  console.log('开始');
  await sleep(1000); // 等待 1 秒
  console.log('1 秒后');
}

2. debounce 防抖函数 ​

创建防抖函数。

参数说明：

参数类型必填说明
funcFunction是要防抖的函数
waitnumber否等待时间（毫秒），默认 300
immediateboolean否是否立即执行，默认 false

返回值： Function — 防抖后的函数

示例：

ts
import { debounce } from 'l-js-fn';

const handleSearch = debounce((query: string) => {
  console.log('搜索:', query);
}, 500);

// 快速输入时只会在停止输入 500ms 后执行一次
handleSearch('a');
handleSearch('ab');
handleSearch('abc'); // 最终只输出 "搜索: abc"
js

5. deepClone 深拷贝 ​

深拷贝函数，支持循环引用。

参数说明：

参数类型必填说明
objT是要深拷贝的对象
optionsobject否配置选项
options.cloneFunctionsboolean否是否克隆函数，默认 false
options.cloneSpecialObjectsboolean否是否克隆 DOM 节点等特殊对象，默认 false

返回值： T — 深拷贝后的对象

示例：

ts
import { deepClone } from 'l-js-fn';

const obj = { a: 1, b: { c: 2 } };
const cloned = deepClone(obj);

cloned.b.c = 3;
console.log(obj.b.c); // 2（原对象未受影响）

// 循环引用
const a: any = { name: 'a' };
a.self = a;
const clonedA = deepClone(a);
console.log(clonedA.self === clonedA); // true
js

7. syntaxHtmlToJson HTML转JSON ​

8. loadScript 动态加载脚本 ​

动态加载外部 JS 文件。

参数说明：

参数类型必填说明
srcstring | null是JS 文件路径

返回值： Promise<HTMLScriptElement> \| undefined

示例：

ts
import { loadScript } from 'l-js-fn';

await loadScript('https://example.com/sdk.js');
// 脚本加载完成
js
import { loadScript } from 'l-js-fn';

await loadScript('https://example.com/sdk.js');
// 脚本加载完成
js
const { loadScript } = require('l-js-fn');

await loadScript('https://example.com/sdk.js');
// 脚本加载完成

注意

  • 如果脚本已存在（相同 src），返回已存在的 HTMLScriptElement 的 Promise
  • src 为空时返回 Promise.reject
  • 仅在浏览器环境中可用

11. imageToBase64 图片转Base64 ​

将图片转换为 Base64 字符串。

参数说明：

参数类型必填说明
inputFile | Blob | string | null是图片 URL 或 File/Blob
typestring否输出类型，默认 'image/png'
qualitynumber否压缩质量（0-1），默认 1

返回值： Promise<Result> — 包含 Base64 字符串的结果对象

示例：

ts
import { imageToBase64 } from 'l-js-fn';

// 从 URL 转换
const result = await imageToBase64('https://example.com/image.png');
console.log(result.data); // 'data:image/png;base64,...'

// 从 File 对象转换
const file = document.querySelector('input[type="file"]').files[0];
const result2 = await imageToBase64(file, 'image/jpeg', 0.8);
js

注意

  • imageToBase64 仅在浏览器环境中可用（依赖 Canvas API）
  • 当 input 为 null 时，返回 Result.fail('输入不能为空')，不会抛出异常

12. retry 异步重试 ​

异步函数失败重试。

ts
import { retry } from 'l-js-fn';

const fetchData = retry(
  async () => {
    const res = await fetch('/api');
    if (!res.ok) throw new Error('request failed');
    return res.json();
  },
  { times: 3, delay: 1000 }
);

await fetchData(); // 失败后最多重试 3 次
js

13. once 只执行一次 ​

包装函数使其只执行一次。

ts
import { once } from 'l-js-fn';

const init = once(() => {
  console.log('初始化');
  return 'done';
});

init(); // 输出 '初始化' → 'done'
init(); // 直接返回 'done'（无输出）

14. memoize 缓存计算结果 ​

缓存函数计算结果，相同参数不重复执行。支持自定义缓存上限，默认 200 条。

参数说明：

参数类型必填说明
fnT是需要缓存的函数
maxSizenumber否最大缓存条目数，默认 200，设为 0 则不限制
ts
import { memoize } from 'l-js-fn';

const add = memoize((a: number, b: number) => {
  console.log('计算中');
  return a + b;
});

add(1, 2); // 输出 '计算中' → 3
add(1, 2); // 直接返回 3（缓存命中，无输出）
add(2, 3); // 输出 '计算中' → 5（不同参数重新计算）

// 自定义缓存上限
const fn = memoize(expensiveFn, 100);
js
import { memoize } from 'l-js-fn';
