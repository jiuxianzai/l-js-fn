date-kit — 日期处理 ​

日期处理工具集，提供格式化、计算、转换等常用功能。

1. dateFormat 日期格式化 ​

将日期或时间戳格式化为指定格式的字符串。

参数说明：

参数类型必填说明
inputDate | string | number否输入，默认当前时间
formatstring否输出格式，默认 'yyyy-MM-dd HH:mm:ss'

返回值： string — 格式化后的日期字符串；无效输入返回 ''

支持的格式符：

格式符说明
yyyy四位年份
MM月份（01-12）
dd日期（01-31）
HH小时（00-23）
mm分钟（00-59）
ss秒（00-59）
SSS毫秒（000-999）
q季度（1-4）

示例：

ts
import { dateFormat } from 'l-js-fn';

dateFormat(new Date());                        // '2024-01-01 12:00:00'
dateFormat(new Date(), 'yyyy-MM-dd');          // '2024-01-01'
dateFormat(1704067200000);                     // '2024-01-01 00:00:00'
dateFormat('2024-01-01');                      // '2024-01-01 00:00:00'
dateFormat(null);                              // ''
dateFormat(new Date(), 'MM/dd');               // '01/01'（支持任意自定义格式组合）
dateFormat(new Date(), 'yyyy年MM月dd日');       // '2024年01月01日'
js

dateFormat(new Date());                        // '2024-01-01 12:00:00'
dateFormat(new Date(), 'yyyy-MM-dd');          // '2024-01-01'

dateFormat('2024-01-01');                      // '2024-01-01 00:00:00'
dateFormat(null);                              // ''
dateFormat(new Date(), 'MM/dd');               // '01/01'（支持任意自定义格式组合）
dateFormat(new Date(), 'yyyy年MM月dd日');       // '2024年01月01日'
js
const { dateFormat } = require('l-js-fn');

dateFormat(new Date());                        // '2024-01-01 12:00:00'
dateFormat(new Date(), 'yyyy-MM-dd');          // '2024-01-01'
dateFormat(1704067200000);                     // '2024-01-01 00:00:00'
dateFormat('2024-01-01');                      // '2024-01-01 00:00:00'
dateFormat(null);                              // ''
dateFormat(new Date(), 'MM/dd');               // '01/01'（支持任意自定义格式组合）
dateFormat(new Date(), 'yyyy年MM月dd日');       // '2024年01月01日'

提示

format 参数支持任意 token 组合（yyyy/MM/dd/HH/mm/ss/SSS/q），不限于 DATE_FORMAT 常量。DATE_FORMAT 只是常用格式的快捷常量。

2. dateSecond 秒数转时间 ​

将秒数转换为 HH:mm:ss 格式。

参数说明：

参数类型必填说明
valuenumber是秒数

返回值： string — 格式化后的时间字符串

示例：

ts
import { dateSecond } from 'l-js-fn';

dateSecond(3661);   // '01:01:01'
dateSecond(59);     // '00:00:59'
dateSecond(86400);  // '24:00:00'
dateSecond(-1);     // '00:00:01'（负数取绝对值处理）
js

3. dateDiffDays 计算天数差 ​

计算两个日期之间相差的天数（忽略时分秒）。

参数说明：

参数类型必填说明
date1Date | string | number是第一个日期
date2Date | string | number是第二个日期

返回值： number — 相差的天数（非负数）

示例：

ts
import { dateDiffDays } from 'l-js-fn';

dateDiffDays('2024-01-01', '2024-01-03');          // 2
dateDiffDays(new Date('2024-01-01'), new Date('2024-01-10')); // 9
js
import { dateDiffDays } from 'l-js-fn';

js

4. dateFormatPassTime 相对时间格式化 ​

格式化过去时间为相对时间字符串。

参数说明：

参数类型必填说明
startTimestring | number | Date否起始时间，默认当前时间

返回值： string — 相对时间描述

示例：

ts
import { dateFormatPassTime } from 'l-js-fn';

dateFormatPassTime('2020-01-01 12:12:12'); // '3年前'
dateFormatPassTime(new Date());             // '刚刚'
dateFormatPassTime(Date.now() - 60000);     // '1分钟前'
js

5. dateMonthDays 当月总天数 ​

获取指定日期月份的总天数。

参数说明：

参数类型必填说明
timeDate | string | number是日期

返回值： number — 当月天数

异常： 无效日期输入时抛出 Error('Invalid date')

示例：

ts
import { dateMonthDays } from 'l-js-fn';

dateMonthDays('2023-02-01'); // 28
dateMonthDays('2024-01-01'); // 31

6. dateDiff 计算时间间隔 ​

计算两个时间的间隔（单位：毫秒）。

参数说明：

参数类型必填说明
startDate | string | number是开始时间
endDate | string | number是结束时间

返回值： number — 时间间隔（毫秒）

异常： 类型不一致或格式无效时抛出 Error

示例：

ts
import { dateDiff } from 'l-js-fn';

dateDiff('2024-01-01', '2024-01-02'); // 86400000（1天）
dateDiff(new Date('2024-01-01'), new Date('2024-01-02')); // 86400000
js

js

7. dateDiffTime 计算时间差值 ​

计算两个时间之间的差值，返回包含天/时/分/秒的结构化结果。

参数说明：

参数类型必填说明
date1Date | string | number是第一个日期
date2Date | string | number是第二个日期

返回值： { days: number; hours: number; minutes: number; seconds: number } — 各分量均为非负数

示例：

ts
import { dateDiffTime } from 'l-js-fn';

dateDiffTime('2024-01-01 10:00:00', '2024-01-02 12:30:45');
// { days: 1, hours: 2, minutes: 30, seconds: 45 }

dateDiffTime('2024-01-01', '2024-01-01 01:02:03');
// { days: 0, hours: 1, minutes: 2, seconds: 3 }

dateDiffTime('2024-01-01 23:30:00', '2024-01-02 01:15:30');
// { days: 0, hours: 1, minutes: 45, seconds: 30 }
js

// { days: 1, hours: 2, minutes: 30, seconds: 45 }

// { days: 0, hours: 1, minutes: 2, seconds: 3 }
js
