# l-js-fn v2.x 文档归档

> [!WARNING]
> 本页面为 **v2.x** 历史版本文档归档，该版本已停止维护，仅作存档参考。建议升级到最新版本，如需了解 v3 的破坏性变更，请查看[迁移指南](/guide/breaking-changes)。

## 版本概览

v2.x 是 `l-js-fn` 按需导入稳定后的版本线，主要特性：

- 主包全量平铺导出所有工具函数，支持按需导入与 Tree-shaking
- 覆盖类型判断、数组、对象、字符串、日期、数字、URL、颜色等场景
- 双模块格式（ESM + CJS）

## 安装

```bash
npm install l-js-fn@2
```

## 与 v3.x 的主要差异

| 能力 | v2.x | v3.x |
| --- | --- | --- |
| 主包按需导入 | 支持 | 支持 |
| 子模块分包（bom/ws/storage 等） | 不支持 | 支持 |
| 加密模块（SM2/SM4/SM3） | 部分支持 | 完整支持 |

> [!TIP]
> v2.x 中主包已有的函数，在 v3.x 中均保持兼容，可直接升级。仅新增能力需通过子模块入口导入。

## 主要变更时间线

- **v2.2.0**：新增 `arrayDelToIndex` / `arrayDelToEl` / `arrayDelToKey` 数组删除方法
- **v2.0.0**：取消全量导出，保留按需导出
